# SkillSwap

Платформа для обмена навыками: пользователи публикуют предложения обучения своим навыкам и записываются на занятия к другим пользователям.

Финальный проект по Django.

## Возможности

**Гость**
- просмотр опубликованных предложений и профилей пользователей
- поиск и фильтры: категория, уровень, формат, рейтинг

**Пользователь**
- регистрация, вход, выход, профиль с аватаром
- создание предложений (картинки хранятся в Cloudinary), изменение и удаление своих предложений
- новое предложение и изменения опубликованного проходят модерацию
- запросы на занятия: отправка, принятие, отклонение, завершение, отмена
- оценка (1–5) и отзыв после завершённого занятия
- избранное

**Админ**
- модерация предложений и их изменений: подтвердить или отклонить с указанием причины
- изменение и удаление любых предложений
- бан и разбан пользователей
- удаление любых отзывов

**Супер админ**
- всё, что может админ
- назначение и снятие админов
- управление категориями через Django admin (`/admin/`)

## Стек

- Python 3.12+, Django 5.2
- SQLite
- Cloudinary — хранение аватаров и картинок
- django-filter — поиск и фильтрация
- Tailwind CSS (CDN)
- django-debug-toolbar — проверка SQL-запросов

## Структура

```
config/              настройки и главные маршруты
apps/accounts/       пользователи, профиль, роли и бан
apps/skills/         категории, предложения, ревизии, избранное, поиск
apps/bookings/       запросы на занятия
apps/reviews/        отзывы и рейтинг
apps/moderation/     панель модерации и управление пользователями
templates/           html шаблоны
```

## Запуск

1. Клонировать репозиторий и перейти в папку проекта.

2. Создать виртуальное окружение и установить зависимости:
   ```
   python -m venv venv
   venv\Scripts\activate          # Windows
   source venv/bin/activate       # Linux / macOS
   pip install -r requirements.txt
   ```

3. Скопировать `.env.example` в `.env` и заполнить значения:
   ```
   DEBUG=True
   SECRET_KEY=любая-длинная-строка
   CLOUDINARY_CLOUD_NAME=...
   CLOUDINARY_API_KEY=...
   CLOUDINARY_API_SECRET=...
   ```

   **Важно про картинки.** Чтобы аватары и картинки предложений сохранялись в Cloudinary,
   нужно указать **свои** ключи Cloudinary. Их можно получить бесплатно в личном кабинете
   на [cloudinary.com](https://cloudinary.com) (Dashboard → API Keys).

   Без ключей проект тоже запускается и работает полностью, но картинки сохраняются
   локально в папку `media/` вместо Cloudinary.

4. Создать базу данных (категории добавятся автоматически):
   ```
   python manage.py migrate
   ```

5. Создать супер админа:
   ```
   python manage.py createsuperuser
   ```

6. (по желанию) Заполнить базу демо-данными:
   ```
   python manage.py seed_demo
   ```

7. Запустить сервер и открыть http://127.0.0.1:8000
   ```
   python manage.py runserver
   ```

## Демо-аккаунты

Создаются командой `seed_demo`, пароль у всех `demo12345`:

| Логин | Роль |
|---|---|
| anna, max, kate, mike | менторы с опубликованными предложениями |
| john, lena | студенты с запросами и отзывами |
| moderator | админ |

Супер админ создаётся отдельно через `createsuperuser`.

| `/mentors/` | пользователи с опубликованными предложениями |
| `/favorites/` | избранное |
